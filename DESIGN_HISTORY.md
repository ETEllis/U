# Design and build lineage

CDC was discovered and implemented first. U is a later abstraction beneath that experience, proposed in the preserved September 2026 GPT-6 Pro work. Its center is composition with explicit semantic obligations, with the CDC prefix barrier and phase dynamics kept in a specialized profile.

On September 10, source preservation recovered all five supplied files byte-for-byte and extracted all 22 examples matching the historical audit hashes. One Codex pass and one independent Grok pass produced a reconciled five-decision refinement list. No build ran then. The original grammar, historical audit program, reference ledger and structured package were not supplied.

On September 14, Edward authorized implementation and a new GitHub repository. The current build implements deterministic surface elaboration and executable graph reconstruction, separate reference domain modules, conservative static/resource checking, a small independent proof checker, evidence identity, tooling, bounded native/WASM lowering, and an independent CDC primitive bridge. The original source pin still matched live BiDi main.

Fresh oracle comparison exposed Clang's fused multiply-add behavior, which was incorporated as an explicit numeric profile. Independent review exposed and corrected a dependent binder-shadowing proof flaw, canonical type-tag ambiguity, nonfinite-time admission, malformed access ranges, conflicting probability/choice orders, JSON float overflow, and loss of recurrence tolerances. Each defect is guarded by a permanent regression test. These findings are part of the build lineage; passing the corrected suite does not establish complete implementation correctness.

The manuscript provides scoped mathematical results with explicit premises and a separate small Lean artifact. The formalized definitions are not claimed to prove the Python implementation. The complete original release program remains visible in `CLAIMS.md` and `docs/FULL_COMPLETION_BACKLOG.md`.
