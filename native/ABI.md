# U native bridge ABI 1

The bridge implements values, calls and operating-system access. It neither parses U nor walks a U expression tree. Every U function and lambda becomes a C function. The seed translator is an explicitly disclosed Python bootstrap; subsequent source compilation belongs to `compiler/compiler.u`.

```c
typedef struct UValue *V;
typedef struct UEnv *E;
typedef V (*UFn)(E env, size_t argc, V *argv);
V u_int(const char *decimal);
V u_real(const char *decimal);
V u_text(const char *utf8);
V u_text_n(const char *utf8, size_t bytes);
V u_bool(int truth);
V u_unit(void);
V u_list(size_t count, V *items);
V u_tuple(size_t count, V *items);
V u_record(size_t count, const char **keys, V *items);
V u_closure(UFn fn, E captured, size_t arity);
V u_annotate(V closure, V descriptor);
V u_descriptor(const char *json, size_t bytes);
V u_literal(const char *utf8, size_t bytes);
V u_guard(V value, const char *storage_kind, int nonnegative);
E u_env(E parent);
void u_bind(E env, const char *name, V value);
void u_bind_lazy(E env, const char *name, V initializer);
V u_lookup(E env, const char *name);
V u_member(V object, const char *name);
V u_call(V function, size_t count, V *arguments);
void u_runtime_init(int argc, char **argv);
V u_entry(E root, const char *name);
int u_finish(V result);
```

Include `native/runtime.h` and link `native/runtime.c` with `-std=c11 -ffp-contract=off -lm`. Names are lexical: bindings win over primitive namespaces. Global functions are bound directly; global values are registered with `u_bind_lazy` as zero-argument compiled initializer closures. Lookup forces such a value once and memoizes its result, while reentrant forcing raises `INITIALIZATION_CYCLE`. An unused global value performs no effects. A function creates a child environment, binds its parameters, then evaluates its body. Blocks create child environments. Emit callee and arguments into ordered C temporaries before calling `u_call`; C argument evaluation order is not U's evaluation order. Compound literal arrays are copied by constructors. Runtime strings carry lengths, so embedded NUL values survive; generated string values with NUL must use `u_text_n` or static `u_literal`.

Linux builds additionally link `-lcrypto` for the system OpenSSL SHA-256 implementation. macOS uses CommonCrypto without an additional link flag. `u_guard` checks a storage representation; `numeric` accepts Int or binary64, while other storage names are exact. Its optional nonnegative flag accepts Int values greater than or equal to zero. U compiler code owns the mapping from language annotations to these representation checks.

The native main harness calls `u_runtime_init(argc, argv)`, constructs its global environment, then passes `u_entry(root, name)` to `u_finish`. A constant entry returns its value. A zero-argument function is called without arguments; other function entries parse a JSON argument list from argv[1]. `U_ARGS_JSON` explicitly overrides that argument list. `sys.args()` returns every actual process argument including argv[0]. `u_finish` emits non-Unit results as JSON; Unit exits silently. The empty tuple surface `()` lowers to Unit. `sys.exit` controls explicit driver exit. A process fault writes `U_NATIVE_ERROR <code>: <message>` to stderr and exits 70.

`u_annotate` attaches immutable descriptive data to classical closures. Generated code uses `u_descriptor` for JSON metadata; this constructor caches static literals by address to avoid copying a full descriptor on each closure instantiation. `u_literal` provides the same stable-address cache for ordinary generated text constants. Both require static C literal addresses, never a transient mutable buffer; dynamic text uses `u_text_n`. The JSON is descriptive syntax consumed by U algorithms. The native bridge never executes it. `value.describe` decodes that JSON on first inspection and `value.arity` returns the declared closure arity. Descriptors do not imply proof trust or authorize physical reflection.

## Primitive contracts

All primitive calls check arity and types. Integers are signed, arbitrary-precision base-10^9 limb values, limited by the disclosed process allocation budget rather than silently narrowed to 64 bits. Division truncates toward zero; remainder has the dividend's sign. Natural operations reject negative inputs. Binary floating-point operations use C binary64 with contraction disabled; `math.fma` explicitly requests one-rounding fused multiply-add.

- `int.add/sub/mul/div/mod/eq/ne/lt/le/gt/ge(a,b)`, `int.neg/abs(a)`, `int.to_real(a)`, `nat.zero()`, `nat.succ(n)`, corresponding nonnegative binary operations, `nat.ceil_div(a,b)`.
- `bool.not(a)`, `bool.and/or(a,b)`, `text.concat/eq(a,b)`.
- `text.length(s)`, `text.at(s,i)`, `text.slice(s,start,end)`, `text.from_code(n)`, `text.code(s)`, `text.join(list,separator)`, `text.parse_int(s)`, `text.parse_real(s)`, `text.from_int(n)`, `text.from_real(x)`. Text indices count Unicode scalar values. `text.code` requires exactly one scalar. `text.at` returns empty text exactly at the end; larger or negative indices fail. Slices use a half-open interval and reject invalid bounds. Byte operations are explicitly named `bytes.length/at/slice`; `bytes.at` returns an Int. `bytes.find(text,needle,start)` and `bytes.find_any(text,listOfByteInts,start)` return a byte offset or -1. Byte slices still require a valid UTF-8 result.
- `list.length/get/cons/head_or/tail_or_empty/reverse/append`; append joins two lists. `list.map(xs,f)`, `list.filter(xs,f)`, `list.fold_left(xs,initial,f)` and `nat.rec(n,initial,f)` call compiled U closures. `tuple.first/second/get/length`, `tuple.make(list)`; `record.get(object,key)`, `record.has(object,key)`, `record.keys(object)` preserve insertion order. `record.make(keys,values)` rejects duplicate keys and length mismatch; `record.put(record,key,value)` creates an updated immutable record.
- `cell.new(v)/get(c)/set(c,v)`, `buffer.new()/push(b,v)/get(b,i)/set(b,i,v)/length(b)/freeze(b)`; mutation returns Unit and freeze returns an immutable list snapshot.
- `table.new()/set(table,key,value)/get(table,key,fallback)/has(table,key)` provide a managed mutable hash index with Text keys. Its contents are ordinary data; the U compiler owns symbol and admission policies.
- `value.select(bool,a,b)` is strict in all three arguments; use zero-argument closures for branching. `value.kind(v)` returns `unit`, `bool`, `int`, `real`, `text`, `list`, `tuple`, `record`, `closure`, `namespace`, `cell`, `buffer`, `partial`, `resource`, `table`, `process`, or `future`. `value.equal(a,b)` performs structural equality on ordinary data, identity on mutable/function values. `value.to_text(v)` returns JSON text. `value.fail(message)` raises an explicit fault. `value.unit()` returns Unit; `value.call(closure,list)` applies checked dynamic arguments; `value.describe` and `value.arity` expose classical compiler metadata.
- `control.while(predicateClosure,bodyClosure)` implements an explicit loop; both closures take no arguments, and the predicate returns Bool.
- `resource.new(kindText,payload)` allocates an opaque identity with a live flag; `resource.peek(handle,kind)` reads and `resource.take(handle,kind)` consumes it. A consumed handle fails further access. `resource.kind` reports its live kind. JSON cannot forge this handle. Raw issuance and payload access are trusted library operations: exposing them to untrusted source would bypass any domain-level evidence seal. The compiler must enforce that admission boundary. C owns no quantum, proof, recurrence or CDC law.
- `core.fix_partial(body,initial)` calls `body(again,state)` until it returns `partial.done(value)`. `again(next)` returns an opaque continuation token. The loop consumes it only when directly returned; using it as a normal value raises an error. `partial.value(p)` extracts a completed result. No stack-unwinding shortcut may discard a continuation context.
- `sys.args/read/write/print/exit/exec/getenv` use process argv and explicit UTF-8 files. `sys.exec(listOfText)` invokes an executable with real argv, never a shell command, and removes `U_NATIVE_ALLOW` from the child environment. `sys.print` adds a newline. Missing environment values return empty text. File reads, writes and process launch respectively require `read`, `write`, `exec` in the comma-separated `U_NATIVE_ALLOW` grant; all three are denied by default. `sys.native_names()` lists every registered full primitive name and its reserved native alias.
- `json.parse(text)` and `json.encode(value)` are disclosed native codec debt, not hidden interpreters. JSON objects become records, arrays become lists, null becomes Unit; integer tokens preserve arbitrary precision.
- `f64.add/sub/mul/div/eq/lt/le/gt/ge`, `f32.add/sub/mul/div`, `f32.from_real`, `math.sin/cos/exp/log/sqrt/abs/fma/is_finite`, `random.uniform(seed,index)` with a stateless deterministic 64-bit mix. No domain solver or CDC formula lives here.
- `f64.bits(real)` returns the exact finite IEEE-754 binary64 representation as 16 lowercase hexadecimal digits, preserving signed zero. `crypto.sha256(text)` hashes the exact UTF-8 bytes, including embedded NUL, through CommonCrypto on macOS or OpenSSL on Linux. Canonicalization, domain separation, contracts and artifact identity remain U algorithms.
- `sys.has_cap(name)` tests an exact platform grant; `capability.require(name)` refuses absent grants. U library capability factories can invoke this primitive before minting a specific opaque capability.
- `sys.print` and `sys.stdout_write` require `console`; the latter writes exact text and flushes without a newline. Return-value rendering by `u_finish` remains observer output. `sys.getenv` requires `env` except for the nonsecret driver configuration keys `U_ROOT`, `U_USER_ARGS_JSON`, and `U_NATIVE_LINK_CRYPTO`. Aliasing a namespace does not bypass these runtime checks.
- `sys.stdin_line()` returns a UTF-8 line without its CR/LF terminator, or Unit when EOF precedes any bytes; a line is limited to 1 MiB. `sys.stdin_read(n)` reads up to n bytes, returns Unit if EOF occurs before any bytes, and admits at most 8 MiB per call. A zero-byte request returns empty Text. UTF-8 validity is checked; these primitives do not parse LSP headers or messages.
- `sys.cwd()` requires `read` and obtains the physical working directory from the OS, without trusting `PWD`. `sys.file_kind(path)` requires `read` and uses `lstat` to return `file`, `directory`, `symlink`, `other` or `missing`. `sys.list_dir(path)` also requires `read`; it returns one level of `{name,kind}` entries in OS order, excluding `.` and `..`, with a 100,000-entry ceiling. Recursive traversal, sorting and symlink policy belong to U.
- `sys.mkdir(path)` and `sys.rename(source,destination)` require `write`. Creation is one level and fails if the path exists. Rename uses the platform operation and may replace an existing destination; U installation policy must decide whether that is permitted. These calls make no crash-durability or recursive-copy claim.
- `sys.write_new(path,text)` and `sys.write_bytes_new(path,bytes)` require `write` and create exclusively, refusing an existing path. `sys.write` and `sys.write_bytes` permit replacement. Binary writers accept a list of Int values in 0..255 and validate the entire list before opening the destination. Temporary stream and directory handles are released if a caught error interrupts their operation.
- `crypto.sha256_file(path)` requires `read` and hashes regular-file bytes without UTF-8 decoding. It streams 64 KiB chunks through CommonCrypto on macOS or OpenSSL EVP on Linux; NUL and arbitrary binary bytes retain their exact values. Hashing, lock policy and artifact identity are distinct: U decides which file and contract the digest belongs to.
- `value.try_call(closure, arguments)` returns `{ok:true,value}` or `{ok:false,code,message}` for an ordinary caught runtime fault. It restores call depth, pending control state and interrupted lazy-initialization state, releases transient codec allocations made inside the boundary, and supports nesting. It does not roll back caller mutations or resource consumption. Shared-budget exhaustion, memory failure and continuation-integrity traps stay terminal and cannot be converted into a successful result. Exception frames never cross a worker boundary. U uses this generic mechanism for protocol diagnostics and borrow cleanup; C does not interpret source or proof syntax to recover from an error.

## Isolated workers and shared results

`process.spawn(action)` immediately starts a real OS process executing the compiled zero-argument U closure. Parent cells are copied into the worker's private address space and are not shared mutable state. Every opaque resource records its creating process; copied resource handles cannot be used in another process. Workers receive no `U_NATIVE_ALLOW` grants by default. `process.spawn_with_caps(action, names)` verifies each requested grant against the parent's explicit grants, then transfers only that subset. Worker code that needs an opaque resource must create it locally or use a specifically admitted immutable data snapshot.

The returned process handle carries ownership of waiting, cancellation and issuance of result-reading rights. `process.poll(handle)` returns its current outcome. `process.wait(handle, timeout_ms)` observes until completion or timeout; -1 waits without a deadline. `process.cancel(handle)` requests termination; it never implies rollback of effects. Only the creating process may use these three owner operations. `process.sleep(milliseconds)` provides an OS timer, limited to one day per call.

`process.share(handle)` creates a read-only future that can be captured by other workers. `process.observe(future)` checks it without blocking; `process.result(future, timeout_ms)` waits for an outcome. Reading does not consume another subscriber's result. The implementation stores immutable tagged data in an unlinked temporary file and uses a separate completion pipe. EOF wakes every reader even when the producer terminates before writing a result, so failure does not require the parent to poll. A small shared status mapping carries completion and cancellation flags. These are generic OS scheduling, storage and transport mechanisms; Task and dependency policies live in U.

Transport preserves Unit, Bool, arbitrary-precision Int, finite binary64 including negative zero, Text, List, Tuple, Record and completed Partial. It rejects closures, mutable cells/buffers/tables, resource handles and process/future authority. Binary64 transport uses an exact hexadecimal representation, not a lossy decimal cast. A worker outcome is `{state, value, error, cancellation_requested}`, with state `running`, `completed`, `failed` or `cancelled`. Results are limited to 64 MiB and 128 nested transport nodes along a path. At most 64 active workers are admitted; terminal owners are reaped, and outstanding owned workers are terminated when their creating program exits.

`stdlib/processes.u` implements lazy Task construction, independent start, observation, pending cancellation, running cancellation requests and autonomous ordinary-data continuation chains. Starting `async.then` starts a coordinator worker that waits through a read-only result right, so its continuation completes without parent observation. Multiple subscribers retain independent reading rights. Resource-producing tasks, including GPU output ownership, require explicit parent transfer; ordinary `async.then` refuses those affine results instead of copying ownership.

The same U module owns deterministic FIFO actor supervision and restart windows, finite temporal reachability/SCC/fairness checks, simultaneous positive-edge U8 register simulation, mutable borrow scopes, and partitioned lane simulation. Actor simulation requires a platform `actors` grant. Clock and GPU construction are inert; clock events and task start explicitly realize them. GPU lanes are simulated U closures, not claims of GPU hardware execution. `temporal.spec` accepts a fourth argument consisting of one fairness value or a list; `without_fairness` is the three-argument form. `temporal.and` takes two conjuncts and `temporal.all` accepts a list. `actor.run` uses a 1000-message limit; `run_steps` takes an explicit limit.

HTTP construction and response policy also live in U. `http.capability()` requires the `network` grant; `http.get(capability,url)` validates that opaque capability and constructs a pending Task. Its worker receives only a verified `network` grant and invokes `http.transport(url)`. The transport uses the fixed `/usr/bin/curl` executable with explicit argv, configuration disabled, no proxy credentials, HTTP/HTTPS-only protocols, five redirects, 15-second total and five-second connection timeouts, and an 8 MiB response limit. It returns status, content type and hexadecimal response bytes. U rejects unsuccessful final response statuses and `http.body_text` decodes UTF-8, ASCII or ISO-8859-1; other declared charsets are explicitly refused. `bytes.from_hex` is the generic byte-to-UTF-8 codec. HTTP TLS and framing belong to the vetted system transport; task sequencing, capability use and response interpretation belong to U.

`stdlib/dynamics.u` owns acausal affine coefficient extraction, initial algebraic-state solving, partial-pivot Gaussian elimination with a 1e-12 pivot tolerance, backward-Euler steps and residual calculation. DAE construction does not sample time-dependent forcing. Numerical solve requires explicit `backward_euler.affine_index1`, a nonempty square system, finite start/coefficients and positive finite dt, and initial values for every differentiated trajectory. Unsupported nonlinear/foreign-trajectory forms and singular systems fail explicitly. The output reports a binary64 approximation with no global-error or physical-backend claim.

Every listed `namespace.operation` has a reserved `native.namespace_operation` alias. Lexical U definitions win over all fallback namespace resolution, including when a U record supplies a standard library namespace. The aliases let those U implementations call specific disclosed bridge operations without accidental self-recursion.

The bridge owns an arena with a default 1 GiB cumulative payload limit, overridable through `U_NATIVE_MEMORY_MB`. Small allocations use zeroed 64 KiB pages; larger values use dedicated blocks. Alignment, page padding and transient codec/OS buffers are additional to the payload count, so this is not a hard resident-memory limit. Transient codec storage has a separate ceiling equal to the configured payload limit and is released after normal use or caught failure. All arena blocks are released at normal shutdown. There is no tracing collector: long-lived workloads must account for retained U values. Call depth and JSON nesting are bounded, and allocation multiplication is checked. Larger lexical environments and the fixed primitive registry use indexes without changing lexical search order or global forward references. Platform primitives are explicit trust requirements. The compiler driver is trusted to use them; untrusted user code requires the compiler's admission policy before launch.

When `U_NATIVE_STEPS` is set, each native closure or primitive dispatch decrements a shared atomic allowance. Forked workers share the same allowance, so spawning workers does not multiply it. Exhaustion raises `BUDGET_EXHAUSTED` and cannot produce a successful final return value. This measures native call dispatches, not abstract language steps or wall-clock time. The trusted compiler may leave the allowance unset; user launch policy chooses its default. Already-authorized side effects are not rolled back by exhaustion.

## Reproducibility

The independent Python seed may have different initial formatting. The authoritative fixed point is compiled U compiler stage 1 producing stage 2 C, then stage 2 producing stage 3 C, with byte-identical generated C and matching program behavior. Any seed equality is additional evidence, not a substitute for that fixed point.
