# U research page

Serve the repository root with a local static server, then open `/landing/`. Serving the root makes the sibling PDF link available. No build step, external fonts, tracking or third-party JavaScript is required.

The kernel selector and independence explorer are educational models. The explorer applies the stated finite footprint rule to four explicitly declared resource arrangements. It does not call the U compiler, execute a U program, manufacture a proof or issue an authority-bearing receipt. Current implementation claims are routed to the repository's claim ledger.

Keyboard support: the constructor tabs use Left/Right, Home and End; ordinary navigation uses native links, inputs and selection controls. The layout responds to narrow screens and honors reduced-motion preferences. The page is staged locally and in the repository; no public deployment is implied.
